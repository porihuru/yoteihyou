# 予定表

Edge 95 と Internet Explorer 11（IEモードを含む）で動作する、SharePointリスト連携の月間予定表です。

## 表示と印刷

画面上部で次の表示を切り替えます。

- 日々: グループを縦、時刻を横にして1日分を表示。印刷の初期設定はA3横
- 週間: 月曜日から日曜日までを表示。印刷の初期設定はA4縦
- 月間: 月間カレンダーを表示。印刷の初期設定はA3横

下へスクロールしても、データ接続・操作欄と日々の時刻行、週間・月間の日付見出しを画面上部に固定します。月間の横スクロールにも見出しを合わせます。IE11向けにJavaScriptで固定し、印刷時は通常のレイアウトに戻します。

「印刷」または `Ctrl+P` で印刷プレビューを開きます。A4/A3、縦/横、印刷するグループ、横と縦の縮尺を選び、確認してから「印刷する」を押します。内容は用紙に収まる基準寸法で配置され、縮尺はその基準に対する割合です。横の縮尺は列幅、縦の縮尺は行高を変更し、文字は縦横比を保って大きさを変えます。用紙からはみ出す場合は警告を表示します。設定は日々・週間・月間ごとにCookieへ保存され、「設定」のCookie初期化で削除できます。余白は `js/config.js` の `print.marginMm` で変更できます。

予定の入力時に「日々」「週間」「月間」から反映先を複数選択できます。反映先が保存されていない従来データは、3つすべてに表示します。

## 入力と修正

起動時の予定表は「読取専用」です。予定や組織設定を変更するときは画面上部の「予定表更新」を押してください。作業後は「更新終了」で読取専用へ戻せます。接続先を切り替えた場合も読取専用に戻ります。更新モードは端末へ保存しません。

- 表示中の予定をクリックすると、内容を直接修正できます。
- 月間画面は日付枠の空白、週間画面は各日の予定欄の空白をクリックして新規入力します。クリックした日付が開始日時・終了日時へ自動設定されます。
- 日々画面は時間枠の空白をクリックして新規入力します。クリックした日付と時刻が開始日時へ入り、終了日時は設定された標準時間後になります。
- 編集中は画面を分割し、左側4分の3に予定表、右側4分の1に入力・修正画面を表示します。
- 入力・修正画面は取消ボタンまたはEscキーで閉じられます。
- 試験用CSVでも新規登録・更新・削除を試せます。変更は画面上だけに反映され、再読込・接続先切替・ページ終了で消えます。CSVファイル自体は更新しません。

週間・月間は日付ごとの表のまま、日々と同じ線種・色、時刻・件名・場所を表示します。予定を日付やグループへドラッグして移動でき、予定の左右端を別の日付へドラッグすると開始日・終了日を変更できます。右クリックまたは `Ctrl+C` / `Ctrl+X` / `Ctrl+V` のコピー・切り取り・貼り付けにも対応します。週間・月間には分単位の時間軸がないため、ドラッグで日付を変更しても元の時刻は維持します。時刻そのものは予定編集画面で変更してください。

日々画面の時間枠は `js/config.js` の `dailyView` で変更できます。通常は7時から18時までを表示します。6時台または18時以降は、その時間帯に同日内で完了する時間指定予定がある場合だけ表示します。終日予定と複数日にまたがる通し予定は表示範囲を広げる判定に含めません。表示可能範囲は6時から22時、目盛りは1時間単位、標準予定の開始時刻は9時、標準時間は1時間です。

日々画面では、表の時刻目盛りを `0900` 形式で表示します。予定は実際の開始・終了位置を横線で結び、両端へ時刻、線の下へ「件名（場所）」を表示します。多くの予定を表示できるよう、文字サイズを維持して上下の余白を詰めています。予定内の上下余白は各1px、グループ枠側は各2px、予定段の間隔は2pxです。時間が重なる予定は別の表示行へ自動配置します。

日々画面では次の操作にも対応します。時間の変更は15分単位です。

- グループ名の左にある「－」で最小化し、「＋」で展開できます。大グループを最小化すると配下の小グループをまとめて隠し、小グループを最小化するとその予定行を隠してグループ名の1行だけを残します。この状態は日々・週間・月間の表示を切り替えても維持します。
- 件名をドラッグすると、時刻またはグループを変更できます。
- 横線の前端・後端にあるつまみをドラッグすると、開始時刻・終了時刻を変更できます。
- 予定を右クリックすると、コピー、切り取り、貼り付けを選べます。貼り付け先のグループと時刻を右クリックしてから貼り付けます。
- 予定を選択した状態では `Ctrl+C`、`Ctrl+X`、`Ctrl+V` も使用できます。コピーは新しい予定を作成し、切り取り後の貼り付けは元の予定を移動します。
- 試験用CSVでは画面内だけを変更し、SharePoint接続時はSharePointへ登録・更新します。

## データ接続先

画面上部の「データ接続」で切り替えます。

- **試験用CSV**: `data/schedule.csv` を `XMLHttpRequest` で読み込みます。画面上では編集できますが、CSVファイルには保存しません。
- **SharePoint**: SharePoint REST APIを使用し、予定の読込・登録・更新・削除を行います。

SharePoint接続では、現在表示している日・週・月と期間が重なる予定だけを取得します。表示期間を移動すると、その期間の予定を再取得します。

最後に選択した接続先は `localStorage` に保存されます。保存しない場合は `js/config.js` の `rememberDataSource` を `false` にしてください。

## SharePointリスト

### 共通アクセスカウンター

全利用者で共有する累計アクセス数を表示するには、SharePointカスタムリスト「予定表アクセスカウンター」を作成し、内部名 `VisitCount` の数値列を追加してください。標準の `Title` が `予定表`、`VisitCount` が `0` の項目を1件作成します。リスト名と項目タイトルは `js/config.js` の `sharePoint.accessCounter` で変更できます。全閲覧者に、このカウンター項目の読込・更新権限が必要です。

ページを開いたときに1回加算します。画面内の再読込や表示切替では加算しません。同時更新で競合した場合は再取得して最大5回試します。現在は暫定値として「アクセス 123」を表示し、SharePointから取得できた場合は実数に切り替えます。リストの準備や権限が足りない場合も暫定値123のまま予定表の表示を継続します。カウンターの更新は、予定表の「読取専用」とは独立しています。

### 操作履歴リスト

予定の新規作成・更新・削除は、別のSharePointカスタムリスト「予定表操作履歴」に記録します。日々画面でのドラッグによる時刻・グループ変更や貼り付けも対象です。画面の「印刷」の横にある「履歴」から最新300件を確認できます。更新では変更前と変更後、削除では削除前の内容を表示します。操作者と操作日時は履歴リスト標準の「作成者」「作成日時」を使用します。

履歴リストには標準の `Title` 列に加え、次の列を作成してください。内部名を正確に合わせ、`BeforeJson` と `AfterJson` は「複数行テキスト」のプレーンテキストとしてください。

| 表示名の例 | 内部名 | 種類 |
|---|---|---|
| 操作 | `Action` | 1行テキスト |
| 予定ID | `ScheduleItemId` | 1行テキスト |
| 予定リスト | `ScheduleList` | 1行テキスト |
| 変更前 | `BeforeJson` | 複数行テキスト |
| 変更後 | `AfterJson` | 複数行テキスト |

履歴は新規登録後、ID順で最新300件を残して古い項目を削除します。履歴リストの名称は `js/config.js` の `sharePoint.history.listTitle` で変更できます。予定の変更と履歴リストへの記録は別のRESTリクエストなので、履歴記録や古い履歴の削除に失敗した場合、予定の変更は取り消されず画面に警告が表示されます。履歴リストの作成・削除権限が必要です。同時操作時には一時的に300件を超えることがあります。試験用CSVでは新規作成・更新・削除を各10件含むサンプル履歴30件と画面内の操作履歴を表示しますが、SharePointへは保存しません。

### 予定リスト

終日入力を保存するため、予定リストに内部名 `AllDay` の「はい/いいえ」列（既定値: いいえ）を追加してください。`js/config.js` の `sharePoint.fields.allDay` に対応します。列追加前はSharePointの読込・保存がエラーになるため、先に列を用意してください。この列はアプリ独自の終日フラグです。

予定入力では開始日・終了日をカレンダーから選択できます（IE11対応）。時刻は0800～1700の15分刻みのプルダウン、または直接入力（0830 / 08:30）に対応します。直接入力は0000～2359まで可能です。「終日」を選ぶと時刻入力を無効にし、選択した開始日から終了日までを含む予定として扱い、日々・週間・月間の予定に時刻を表示しません。終日を解除すると入力済みの時刻を再利用できます。

既存のSharePoint標準「イベント」リストを使用します。アプリが読み書きする列は次のとおりです。

| 表示名 | 内部名 |
|---|---|
| タイトル | `Title` |
| 開始時刻 | `EventDate` |
| 終了時刻 | `EndDate` |
| 分類 | `Category` |
| 場所 | `Location` |
| 説明 | `Description` |
| 目的（入力グループ保存先） | `Purpose` |
| 線種（追加する1行テキスト列） | `LineStyle` |
| 線色（追加する1行テキスト列） | `LineColor` |
| 文字色（追加する1行テキスト列） | `TextColor` |

`LineStyle` と `LineColor` は新たに追加する1行テキスト列です。線種は `solid` / `dotted`、線色は `default` / `red` / `green` / `brown` を保存します。列が未追加でも既存予定は標準の青い実線として読み込めますが、標準以外の線を保存するには両列を追加してください。試験用CSVでは線の変更も画面内のみ有効です。

文字色は線色とは別に設定できます。SharePointに保存する場合は1行テキスト列 `TextColor` を追加し、`default` / `red` / `green` / `brown` を保存します。列がない既存予定は標準色で表示され、標準以外の文字色は列の追加後に保存できます。試験用CSVの文字色変更は画面内のみ有効です。

`ID` は既存の標準列を使用します。入力グループと反映先は `GP1科／GS班｜日々・週間・月間` の形式で「目的」列へ保存します。大グループだけの場合は `GP1｜日々・週間・月間` の形式です。作成者・作成日時・更新者・更新日時はSharePoint標準の `Author` / `Created` / `Editor` / `Modified` を読み取り専用で表示します。CSVにはこれらの情報がないため「情報なし」と表示します。バナーURL、位置情報、空き時間情報、重複予約のチェック、出席者、設備など、アプリで使用しない列は変更しません。

予定の読込時にSharePointのETagを保持し、更新・削除時に同じETagを送信します。読込後にほかのユーザーが予定を変更していた場合は上書きせず、再読込を求めるメッセージを表示します。

## 組織設定

組織設定はSharePointの「予定表組織設定」リストから読み込みます。画面上部の「設定」を開くと、設定の追加・編集・削除、表示順、有効状態、月間・週間・日々の初期行数を変更できます。SharePointへ接続できない場合は `config/organizations.js` をフォールバックとして使用します。

### 組織設定リスト

SharePointでカスタムリストを作成し、次の列を用意します。

| 表示名の例 | 内部名 | 種類 | 用途 |
|---|---|---|---|
| 大グループ | `Title` | 1行テキスト | 必須 |
| 小グループ | `TeamName` | 1行テキスト | 大グループだけの場合は空欄 |
| 月間行数 | `MonthlyRows` | 数値 | 1～50 |
| 週間行数 | `WeeklyRows` | 数値 | 1～50 |
| 日々行数 | `DailyRows` | 数値 | 1～50 |
| 行数を自動調整 | `AutoRows` | はい／いいえ | 初期値は「はい」 |
| 表示順 | `SortOrder` | 数値 | 小さい順に表示 |
| 有効 | `IsActive` | はい／いいえ | 無効な設定は予定表へ表示しない |

リスト名と内部名は [js/config.js](js/config.js) の `sharePoint.organizationSettings` で変更できます。同じ大グループでは、「小グループなし」の設定と小グループ付きの設定を併用できません。

フォールバック設定は従来どおり `config/organizations.js` で管理できます。予定表には `groups` の登録順、その中の `teams` の登録順で上から表示されます。

```javascript
window.YOTEIHYOU_ORGANIZATIONS = {
    separator: "／",
    groups: [
        /* 大グループだけ */
        {name: "GP1", monthlyRows: 5, weeklyRows: 5, dailyRows: 5, autoRows: true},
        /* 大グループ＋小グループ */
        {
            name: "GP1科",
            teams: [
                {name: "GS班", monthlyRows: 5, weeklyRows: 2, dailyRows: 2, autoRows: true},
                {name: "JN班", monthlyRows: 5, weeklyRows: 2, dailyRows: 2, autoRows: true}
            ]
        }
    ]
};
```

`autoRows` は省略時も `true` です。「行数を自動調整」が有効な場合、月間・週間・日々の各表示で予定に必要な行だけを表示し、予定がない場合はグループ名を残す1行だけにします。例えば月間行数が5でも、必要な予定行が1行なら残り4行は表示しません。無効な場合は `monthlyRows`、`weeklyRows`、`dailyRows` の行数を最初から確保します。どちらの場合も予定が設定行数を超えたときは、予定を欠落させないため必要数まで増やします。空白セルをクリックすると、その日付とグループを入力画面へ自動設定します。設定ファイル外のグループが既存予定に保存されている場合は、設定済みグループの後に追加表示して値を保持します。

## 設定

`js/config.js` の次の項目を環境に合わせて変更します。

```javascript
sharePoint: {
    siteUrl: "https://サーバー/サイト/サブサイト",
    listTitle: "予定表"
}
```

`siteUrl` が空欄の場合は `_spPageContextInfo.webAbsoluteUrl` を使用します。それも取得できない場合は、配置URL中の `SiteAssets`、`Documents`、`DocLib` などからサイトURLを推定します。確実に接続するには `siteUrl` を明示してください。

リスト名や内部名を変更した場合は、同じファイルの `listTitle` と `fields` を変更します。

## 試験用CSV

`data/schedule.csv` の列構成は次のとおりです。

```text
ID,Title,EventDate,EndDate,Category,Location,Description,Purpose
```

- 文字コード: UTF-8（BOMあり・なしの両方に対応）
- 日時: `YYYY-MM-DD HH:mm`
- カンマや改行を含む値: ダブルクォートで囲む

ブラウザの制約上、CSVをサーバー上へ直接上書きしません。試験中の編集結果を保存する場合もSharePointへ切り替えます。

同梱のサンプルには、2026年9月・10月の平日について設定済みの全グループの予定を収録しています。土日に開始する予定はありません。GP2～GP5は平日1日4件、その他は平日1日1件です。全1,587件を日々に表示し、週間は794件（約50％）、月間は317件（約20％）に絞っています。GP1には日またぎ・週またぎ・月またぎの確認用予定もあり、これらは全表示に残します。サンプルを同じ条件で作り直す場合は次を実行します。

```powershell
node scripts/generate-sample-schedule.js
```

## 配置

リポジトリ一式を同じ構成のまま配置します。SharePointの読込・登録・更新・削除を使用する場合は、認証CookieとREST APIへ同一オリジンでアクセスできるSharePointサイト内への配置を基本としてください。

IISなどSharePointとは別オリジンのWebサーバーへ配置する場合、そのままではブラウザの同一オリジン制約によりSharePoint REST APIへ接続できないことがあります。別オリジンで運用するには、認証を引き継ぐ同一オリジンのリバースプロキシなどを別途用意してください。CORSを許可するだけでは、環境の認証方式によっては接続できません。

CSV読込もHTTP/HTTPS経由で行うため、`index.html` をローカルファイルとして直接開くより、Webサーバー上で確認してください。

## テスト

追加パッケージは不要です。Node.jsが利用できる環境で次を実行します。

```text
node tests/run-tests.js
```

## VS Codeで実行

このフォルダーをVS Codeで開き、F5キーを押して「予定表をブラウザーで開く」を選択します。ローカル開発サーバーが `http://127.0.0.1:8765` で起動し、準備完了後にWindowsの既定ブラウザーが開きます。ブラウザーへのデバッガー接続は行わないため、アタッチ設定は不要です。停止はShift+F5です。

8765番ポートを変更する場合は、VS Codeを起動する前に環境変数 `YOTEIHYOU_PORT` を設定してください。

## IE11互換方針

- JavaScriptはES5構文のみ
- `XMLHttpRequest` を使用
- `let`、`const`、アロー関数、`async/await`、`fetch`、`Promise`、`padStart` は不使用
- 外部ライブラリ、ES Modules、CSS Grid、Flexboxの `gap`、`position: sticky` は不使用
